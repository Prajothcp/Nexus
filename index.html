📘 Inside Aether Nexus: How This App Is Built

A beginner-friendly breakdown of the 4 core layers powering this single-file web application

1. HTML5 Structure & Canvas

The skeleton uses semantic tags (<header>, <main>, <section>) and high-speed drawing surfaces (<canvas>) where JavaScript paints 3D worlds and particles 60 times per second.

2. CSS Glassmorphism & Variables

Translucent panels use backdrop-filter: blur(16px) and CSS custom properties (--accent-primary) so clicking the theme button recolors the entire interface instantly.

3. Real-Time Render Loop

Using requestAnimationFrame(), the browser updates only the active module's physics math, keeping the animation silky smooth at 60 FPS without draining CPU.

4. Procedural Web Audio Synth

Every click, launch chime, and musical note is synthesized mathematically using the browser's AudioContext—zero external audio files required.
